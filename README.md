# 쉬운 블로그 글쓰기

초보자용 네이버 블로그 글쓰기 도우미. 설치 없이 `index.html` 을 열면 바로 쓸 수 있어요.

## 사용법
1. 카테고리(맛집·여행·제품 리뷰·일상)와 주제, 말투를 고르고 **✍️ 글쓰기** 클릭
2. ChatGPT가 새 탭에서 열리고 질문이 자동으로 들어감 (질문은 클립보드에도 복사됨)
3. ChatGPT 답변을 복사해 붙여넣고 **글 가져오기** → 제목·본문·태그 자동 입력
4. 글자 수·빈칸·사진 자리·과장 표현 검사 확인
5. **제목 / 본문 / 태그 복사** → 네이버 블로그 글쓰기 창에 Ctrl+V

ChatGPT 없이 쓰려면 **빈 글 틀로 직접 쓰기** 버튼을 누르면 돼요.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 |
| `style.css` | 꾸밈 |
| `app.js` | 동작 (질문 만들기, ChatGPT 답변 정리, 검사, 복사) |
| `templates.js` | 카테고리별 글 틀 — 글 틀을 바꾸려면 이 파일만 수정 |

API 키나 서버가 필요 없고, 쓰던 글은 브라우저에 자동 저장돼요.
